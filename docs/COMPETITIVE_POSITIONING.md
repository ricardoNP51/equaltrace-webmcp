# Competitive positioning

## Category

Runtime protection parity for agent-operable websites.

## Sharp distinction

- Inspectors answer: **What tools exist?**
- Contract evaluators answer: **Did the tool call succeed?**
- Agent benchmarks answer: **Could the agent complete the task?**
- Accessibility scanners answer: **Does this interface violate known rules?**
- EqualTrace answers: **Did the agent bypass a protection that constrained the equivalent human action?**

## Defensibility

EqualTrace combines four layers that are usually separate:

1. Three-route runtime capture.
2. Semantic protection invariants.
3. First-divergence evidence.
4. Human-approved capability repair and rerun proof.

The competition build must preserve this full chain. Removing any layer turns it into an existing category.

## Audience

- Product and platform teams adding WebMCP.
- Trust, safety, accessibility, and QA engineers.
- Reviewers of consequential commerce, finance, healthcare, privacy, and account-management flows.

## Expansion after the challenge

- Fixture authoring SDK.
- CI regression runner against deployed WebMCP sites.
- Industry-specific invariant packs.
- Browser trace capture adapters.
- Pull-request reports and evidence retention.

These are roadmap items, not challenge-scope commitments.
