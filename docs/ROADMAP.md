# Roadmap to submission

Deadline: 2026-09-03 13:00 PDT (16:00 Bolivia). Internal submission freeze: 2026-09-02 18:00 Bolivia.

## Gate 0 — Documentation foundation (Aug 26)

- Repository, license, architecture, fixture contracts, and handoff.
- Deterministic broken/repaired scenario specified.
- Winning gates, threat model, and submission checklist fixed.

Exit: another PC can begin implementation without reopening product or scope decisions.

## Gate 1 — Native WebMCP proof (Aug 27)

- Scaffold the smallest TypeScript web application and commit its lockfile.
- Add a one-command typecheck/test/build quality gate.
- Deploy the smallest secure build.
- Discover all stable tools in ChatGPT's built-in browser.
- Invoke `equaltrace_run_audit` and observe the same page change.
- Record exact app/browser/version evidence.

Exit: native probe artifact and screenshot/video; no polyfill.

Kill rule: if native registration cannot be made reliable by end of Aug 27, stop UI expansion and resolve that blocker first.

## Gate 2 — Real route capture (Aug 28)

- Visual route through pointer controls.
- Complete keyboard route with logical focus and announcements.
- Agent route through native WebMCP.
- All routes use the same seed and reset contract.

Exit: replayable traces generated by interactions, not fixture-only arrays.

## Gate 3 — Parity engine (Aug 29)

- Normalize checkpoints and evidence.
- Detect first divergence.
- Score all six invariants.
- Export a schema-valid receipt.

Exit: broken scenario fails on exact known divergence; repaired scenario passes.

## Gate 4 — Human-approved repair (Aug 30)

- Agent stages a bounded repair proposal.
- Human sees exact diff and consequences.
- One-use commit tool appears only after approval.
- Use, expiry, reset, revocation, and drift remove the tool.

Exit: lifecycle tests and native evidence pass.

## Gate 5 — Product and accessibility polish (Aug 31)

- High-impact opening state.
- Timeline and divergence readable in under 10 seconds.
- Responsive layouts: 390×844, 1440×900, 1920×1080.
- Keyboard-only completion, visible focus, live-region announcements, reduced motion.

Exit: no console errors, overflow, dead controls, or critical accessibility findings.

## Gate 6 — Reliability and evidence (Sep 1)

- Unit, integration, browser E2E, native probe, clean-clone verification.
- Deployment health check.
- Threat model and known limitations current.
- Public repository contains no secrets or fabricated evidence.

Exit: one-command local check and recorded deployment smoke pass.

## Gate 7 — Submission (Sep 2)

- Record and edit a 2:45–2:58 demo.
- Complete Devpost description using actual evidence.
- Validate all public links in a signed-out/fresh session.
- Freeze release tag `challenge-v1.0.0`.

Exit: submission complete before internal freeze; Sep 3 remains buffer only.
